# 테마 md 형식 v1 (`wg: theme/1`)

사용법: 사용자가 "테마 md", "관심그룹 md", "관심그룹으로 정리"를 요청하면 이 형식으로 파일 1개를 만든다. 여러 종목이 묶이는 테마·공급망 기사를 [기본 분석]한 뒤에는 "관심그룹 md로 만들까요?"를 한 줄로 제안한다.
대상: economist.kr 관심그룹(`wg_group`·`wg_item`). 기존 「그룹 관리 · 일괄등록」 표 붙여넣기의 상위 호환이다.

## 1. 파일
- 파일명 `{그룹명}_{asof}.md` (예 `아틀라스테마_2026-10-26.md`) · UTF-8 · 전체 15,000자 이하
- 파일 하나 = 관심그룹 하나. 같은 테마를 갱신할 때는 같은 그룹명으로 새 파일을 만든다 (가져올 때 '갈아끼우기')

## 2. 뼈대 (순서 고정)

```
---
wg: theme/1
group: 아틀라스테마
asof: 2026-10-26
base: close
vars:
review: 2026-11-17
source: https://…
made: 2026-10-26 claude-chat
---

# 제목 한 줄 (사람용)

## 등록

### 구분행 제목
| 종목 (코드) | 근거 | 트리거 | 무효 | 메모 |
|---|---|---|---|---|
| 나무가 (190510) | [단독] … | 22,850 | 11,050 | … |

## 노트
## 일정
## 출처
참고용 분석, 투자자문 아님
```

## 3. 머리말 (`---` 사이 · `키: 값` 한 줄씩 · 주석 금지)

| 키 | 필수 | 값 |
|---|---|---|
| wg | ✓ | `theme/1` 고정 — 임포터가 이 줄로 형식을 알아본다 |
| group | ✓ | 그룹명 1~30자. `보유종목`·`Top-Pick`·`최근조회` 불가 |
| asof | ✓ | 기준일 `YYYY-MM-DD` = 기사 직전 종가일. 장 마감(15:30) 뒤 기사면 그날, 장중·장전 기사면 직전 거래일 |
| base | ✓ | `close` (asof 종가를 기준가로) · `now` (가져오는 순간 현재가) · `none` |
| vars | | 그룹 변수 이름. 콤마로 최대 4개, 첫째 = 주 변수. **이미 등록된 변수만** (2026-10-26 기준 `미국 USD`, `WTI`). 없으면 비움 |
| review | | 다시 볼 날 `YYYY-MM-DD` (보통 다음 실적·결과 발표 다음 날) |
| source | | 원 기사 URL 하나 |
| rebase | | `yes`면 갈아끼우기 때 기존 기준가도 새로 계산. 기본은 이어받음 |
| made | | `YYYY-MM-DD claude-chat` |

## 4. `## 등록` 영역 — 임포터가 읽는 유일한 곳
- 이 영역에는 `###` 구분행 줄, 표, 빈 줄만 둔다. **문장·불릿 금지** (기존 붙여넣기 파서는 56자 이하 한 칸 줄을 전부 구분행으로 읽는다)
- 구분행 `### 제목`: 50자 이하(토큰 포함), 숫자로 시작하지 않는다
  - 방향은 제목 끝 토큰으로만 적는다. `{↑ 미국 USD}` = 그 변수가 오를 때 유리, `{↓ WTI}` = 내릴 때 유리. 변수는 vars에 있는 이름이어야 하고, vars가 비었으면 토큰을 쓰지 않는다
  - 제목에 방향 단어(상승·하락·오를·내릴·인상·인하·↑·↓·불리·피해)를 쓰지 않는다 — 기존 파서가 방향으로 오인한다
- 표 머리줄은 `| 종목 (코드) | 근거 | 트리거 | 무효 | 메모 |`로 고정한다
  - 종목: `KRX 정식 종목명 (6자리 코드)`. 코드 필수, 이름은 마스터 대조용. ETF는 넣지 않는다
  - 근거: `[공시]` `[IR]` `[리포트]` `[기사]` `[단독]` `[추정]` 중 하나로 시작
  - 트리거·무효: 원 단위 숫자만(콤마 가능), 없으면 빈칸. 출처 있는 가격(상한가 종가·52주 고저 등)이나 계산값만 쓰고, 무엇인지는 메모에 적는다
  - 메모: 조건·리스크·숫자. 직접 계산은 (계산), 해석은 (추정)
  - 한 행의 근거+트리거+무효+메모 합계 400자 이하 (관심그룹 메모 상한 500자)
- 같은 종목은 파일 전체에서 한 번만 (그룹 안 중복 불가). 그룹당 30종목 이하, 권장 3~15
- 민감도·상관계수 열은 넣지 않는다 (사용자가 기각한 항목)

## 5. 나머지 영역 (사람용 · 테마 노트로 보관)
- `## 노트`: [기본 분석]의 요지·핵심 판단·체크포인트·긍정 요인·반대 근거를 짧게
- `## 일정`: `| 날짜 | 내용 | 종목 |` 표. 날짜는 `YYYY-MM-DD`·`YYYY-MM`·`YYYY`·`미정`, 종목은 코드를 콤마로
- `## 출처`: `- [제목](URL)` 목록. 마지막 줄에 `참고용 분석, 투자자문 아님`

## 6. 파일 내기 전 확인
- 모든 종목코드·정식 종목명을 웹 검색으로 확인했다
- asof를 기사 게시 시각 규칙대로 정했다
- 트리거·무효 숫자마다 출처나 계산 근거가 메모에 있다
- 등록 영역에 문장이 없고, 중복 종목이 없고, 행당 400자 이하다
- 전체 15,000자 이하다

## 7. 임포터 전 · 지금 쓰는 법
`## 등록` 영역만 복사 → 관심그룹 「그룹 관리 · 일괄등록」에 붙여넣기 → 새 그룹 이름 입력 → 추가. 구분행·종목·메모가 들어간다(기준가·변수·노트는 빠진다).
asof가 오늘이면, 장 마감 뒤 다음 날 09:00 전에 「기준가 = 현재가 (전체)」를 누른다. 그러면 기준가가 그날 종가가 된다.
